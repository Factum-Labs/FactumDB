# Offline PDF fonts

Noto Sans, Noto Sans Sinhala and Noto Sans Tamil from the Google Fonts
repository (ofl/notosans, ofl/notosanssinhala, ofl/notosanstamil).
These files are bundled assets, never downloaded by the app.

Variable TTF sources were instantiated at their default axes with fonttools
4.66.1 to reduce bundled size. All glyphs were retained. Fonts are embedded
and subset into each exported PDF by fpdf2. The adjacent OFL files contain
the copyright and redistribution licenses. Unsupported code points are
shown as Unicode escapes in both preview and PDF.
