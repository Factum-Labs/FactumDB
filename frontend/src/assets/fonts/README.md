# Bundled IBM Plex fonts

These WOFF2 files are bundled with the application so typography works offline.
They contain the Latin subsets of IBM Plex Sans (400, 500, 600) and IBM Plex
Mono (400, 500), sourced from `@fontsource/ibm-plex-sans@5.3.0` and
`@fontsource/ibm-plex-mono@5.3.0`.

The fonts are distributed under the SIL Open Font License 1.1; the license
and copyright notices for each family are included in this directory.
Characters outside these subsets use the system font fallbacks.
